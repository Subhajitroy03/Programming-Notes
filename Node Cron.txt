Node Cron
-----------

Run the following command:

>> npm i node-cron / npm install --save node-cron


Import node-cron and schedule a task:
--------------------------------------

For commonjs
-------------
const cron = require('node-cron');

cron.schedule('* * * * *', () => {
  console.log('running a task every minute');
});

>> cron.schedule(cron expression , function to execute)

How to write CRON expression:

 # ┌────────────── second (optional)
 # │ ┌──────────── minute
 # │ │ ┌────────── hour
 # │ │ │ ┌──────── day of month
 # │ │ │ │ ┌────── month
 # │ │ │ │ │ ┌──── day of week
 # │ │ │ │ │ │
 # │ │ │ │ │ │
 # * * * * * *
 
 Common Patterns You MUST Know:
 
1. Every second: '* * * * * *'
2. Every minute: '0 * * * * *'
3. Every 5 minutes: '0 */5 * * * *'
4. Every hour: '0 0 * * * *'
5. Every day at 10 AM: '0 0 10 * * *'
6. Every Monday at 9 AM: '0 0 9 * * 1'
7. Every 10 seconds: '*/10 * * * * *'


-->> Special Symbols
 
* → everything  (eg-> * = all values)
*/n → step (interval)   (eg-> */5 → every 5 units)
, → multiple values   (eg- 1,3,5 → specific values)
- → range   (eg- 1-5 → from 1 to 5)
